# Saldo é derivado por um serviço de domínio puro, nunca persistido

"Quem deve a quem" é calculado pela `CalculadoraDeSaldos`, uma função pura sobre Despesas e Pagamentos, sem I/O. O Saldo de um Membro é o que ele pagou em Despesas, menos suas Cotas, mais os Pagamentos que fez, menos os que recebeu. Como cada Divisão fecha, a soma dos Saldos do Grupo é sempre zero, inclusive com divisão não igualitária, e isso é testado. As Transferências sugeridas saem de um algoritmo guloso (casa o maior devedor com o maior credor): no máximo N−1 transferências, determinístico, sem garantia de mínimo ótimo. O saldo não é entidade, porque persistir criaria duas fontes de verdade. O cálculo também não fica no use case, que só carrega os dados e chama o serviço, para que a regra não fique acoplada ao repositório.
