# Reconhecimento de ajuda é derivado só das Contribuições

O ranking de Apoiadores é calculado pelo serviço de domínio puro `ReconhecimentoDeAjuda` a partir das Vaquinhas do Grupo. Não há pontos nem selos persistidos. Só Contribuições contam como ajuda. Pagar Despesas gera Saldo a receber e fazer Pagamentos é obrigação, então nenhum dos dois conta. A ordem é por total contribuído (decrescente), depois por número de Vaquinhas apoiadas, depois pelo nome do Membro. Selos visuais, se existirem, são apresentação no front.
