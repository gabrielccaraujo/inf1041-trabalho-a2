# Toda regra e todo cálculo ficam no backend; o front só apresenta

A API é REST pura sob `/api`, com recursos aninhados em `/api/grupos/{id}/...` (membros, despesas, pagamentos, saldos, vaquinhas, contribuicoes, encerrar, apoiadores). O JSON usa snake_case em português, com valores em `*_centavos`. Erros vêm como `{"erro": "mensagem"}`: 400 para dado malformado, 404 para recurso inexistente e 422 para violação de regra de domínio. As rotas traduzem as exceções de domínio, e o domínio não conhece o HTTP. O front Next.js é um cliente puro que chama `/api/*` pelo proxy do próprio Next, o que dispensa CORS. Ele formata R$, guarda o Membro escolhido, copia a chave Pix ou gera QR e desenha selos e progresso. O front nunca calcula Saldo, Divisão nem ranking, para que a regra não fique duplicada nem sem teste.
