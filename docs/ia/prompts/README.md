# Registro de prompts

Criar um arquivo por intervencao de IA, com ID sequencial (`P001`, `P002`, ...). Guardar o prompt integral e o estado do codigo antes e depois da intervencao. Uma correcao recebe novo ID; nao reescrever registros anteriores.

Copiar `P000-modelo.md` para iniciar um registro. O commit anterior e o commit resultante permitem localizar a versao exata do codigo associada ao prompt.
